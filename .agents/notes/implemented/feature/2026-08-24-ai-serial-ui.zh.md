# Agent Note: AI 连载工作台 UI

Status: implemented

English | [中文](2026-08-24-ai-serial-ui.md)

## Problem

V5 核心与端点就绪,但没有运营者操作面:启用连载要手搓四个 curl,批量起稿没
有按钮,任务结果不看数据库就不可见,路线图的「人工确认」一步也没有可见开关。

## Decision

在 AI 创作中心(`/admin/story`)追加一张新卡,复用页面既有白卡语言
(h-14 渐变头 `#0ea5e9→#2563eb`、p-5 主体、ui.tsx 原语):

- **配置行**——状态 Select(启用/停用)、每日时刻(0-23)、每日生成章数
  (1-20)、发布模式 Select(送审核队列/自动发布)、质检字数下限;一个
  保存连载配置主按钮整包 PUT。头部带实时 已启用/未启用 徽章,状态一眼可读。
- **动作行**——批量生成入队(数量输入 1-50 → POST enqueue)与 立即处理
  队列(POST run;无 pending 时禁用)。处理后:派发 `admin:review-changed`
  让侧栏审核角标更新、重载故事包(章数上限前移)、并按当前书刷新任务表。
- **任务表**——最近 10 条,状态徽章映射(published→已发布/success、
  submitted→待审核/info、rejected→质检拒绝/warning、failed→失败/danger、
  pending|running→排队中|执行中/running),含章号/字数/模型/时间/错误截断
  (悬停看全文);空态引导到上方动作。

加载策略:切书时配置与任务并行拉取;所有变更共用一把 `serialBusy` 锁,双
击不会重复入队。

验证:CDP 审计 **11/11**,全新库单次干净跑(种子书 + 种子 LLM 设置指向本
地 mock 上游,服务器进程**不带任何 AI_\* 环境变量**):卡片以未启用水渲染
→ 保存翻转徽章且跨刷新持久 → 批量入队 2 出提示 → 立即处理队列把两任务经
发现+生成+质检推进为两行 待审核 → 375px 页面零溢出、表格容器内横滚。
typecheck 与生产构建绿。

## Alternatives considered

**独立 /admin/serial 页。**否决:连载是围绕单本书的工作,应紧挨 Story Core
事实与手动生成工作台;独立页会强迫重新选书、割裂同一个心智模型。

**启用用开关(Switch)组件。**ui.tsx 没有该原语;为一个布尔引入新组件只增
面积不复用——Select 与发布模式控件一致,表单更统一。

**入队后自动执行。**刻意不接:入队是意图,执行是执行;分开让运营者可以先
囤一批、核对 pending 数,再一次性清空——与夜间周期同语义。

## Consequences

收益:§8 全闭环可在控制台操作——启用、囤批、立即清或交给调度器过夜跑,
结果一表可查。代价:任务表只展示当前书最近 10 条(更早历史走 API);错误
列截断长的上游报错(悬停可看全文)——在值得做详情抽屉之前可接受。
