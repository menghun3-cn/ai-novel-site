# Agent Note: Production line cards surface key config; editor moves to a drawer

Status: implemented

English | [中文](2026-09-03-production-line-card-and-drawer-editor.md)

## Problem

创作中心的产线(产线)Tab 把运营者最关心的信息藏在了编辑弹窗后面。卡片原本只展示
名称、描述、题材标签和四个聚合统计(今日 / 达标 / 发布 / 通过率)。执行调度
(每日 HH:00 或 手动)**只在产线从未运行过时**渲染:一旦 `lastRunAt` 存在,底栏
就把调度替换成 `上次 X`,运营者不打开编辑器就看不到执行周期。配额(单次 /
每日上限 / 预算)与质量闸门(达标线 / 自动发布)只能在编辑器内看到。编辑器本身
是一个 512px 居中弹窗(`max-w-lg`),承载五个配置区块(调度 / 配额 / 质量闸门 /
创作基线 / 题材清单)——拥挤而局促。

## Decision

重新设计了产线卡片,并把编辑改为右侧抽屉(`web/app/admin/(dash)/creation/page.tsx`)。

卡片现在无需打开编辑器即可看到:

- 一条 执行配置 条(浅灰区块),展示调度(每日 HH:00 / 手动触发)与 每批 N 篇,
  并在配置了单次上限、每日上限、预算 $/日、达标线、自动发布时显示对应小标签。
- 标题旁的 启用 / 停用 徽章与最近一次运行状态徽章(共用 `RunStatus`)。
- 底栏展示上次运行的相对时间与运行标题(触发方式 · 篇数),无运行记录时显示
  尚未运行。

编辑(`LineEditorDrawer`)改用共用的 `Drawer` 组件——右侧滑出、最宽 720px、
整屏高度——取代 `Modal`(512px)。表单区块从灰色 `bg-[#f8fafc]` 块改为白底描边
卡片,以在抽屉的灰色背景上形成对比;抽屉头部通过 `headerExtra` 常显
启用 / 停用 徽章。保存 / 取消固定在底栏。运行与删除确认仍使用弹窗
(`Modal` / `ConfirmDialog`)。

## Alternatives considered

**保留弹窗、只加宽。** 居中弹窗即使加到 `max-w-3xl` 也只是加宽,但它会遮住
产线列表、破坏空间连续性。抽屉让列表始终可见于编辑器旁,并贴合代码库既有的
「列表 → 详情/编辑」次级面板模式(`Drawer` 已用于作品详情)。短确认保留弹窗形式。

**只在产线从未运行过时显示调度。** 这正是被修复的缺陷:一旦存在运行记录,
调度就消失了。把调度、每批篇数、配额、闸门无条件展示在卡片上——标签仅在
配置了对应值时出现——正是本次改动的全部意义。

## Consequences

- 运营者无需打开编辑器即可看到执行周期、每批篇数、配额、预算与达标线,
  上次运行状态一目了然。
- 编辑器约宽 40% 且整屏高,五区块表单不再挤在 512px × 85vh 的弹窗里。
- 运行产线与删除产线的确认仍是弹窗;抽屉只用于编辑。
- 卡片略高,`lg` 两列网格仍可容纳。
